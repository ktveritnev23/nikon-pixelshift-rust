# План: компенсация движения для слияния Pixel Shift

## Алгоритм

После жёсткого выравнивания (сдвиг+поворот, уже работает) каждый кадр отличается от опорного только шумом — везде, кроме движущихся областей. Детекция:

1. **Фазо-инвариантная решётка**: для каждого кадра строится `luma_plane` (суммы блоков 2×2 минус чёрный, гауссово сглаживание σ=0.8) — существующий код `shift.rs`, переводим в `pub(crate)`.
2. **Разностная карта**: решётка кадра ресемплируется через его жёсткое преобразование (обратное к `Shift::map`, аналитически) в координаты опорного кадра, берётся разность с опорной решёткой. Билинейная выборка достаточна: содержимое уже ограничено по полосе блюром.
3. **Блочная маска**: блок B=16 пикселей решётки (32 сенсорных) → энергия разности; локальный шумовой порог = медиана энергий соседних блоков (окно 7×7) — медиана устойчива к тому, что движение занимает малую долю кадра; блок помечается, если его энергия > τ·медианы. τ управляется «чувствительностью» (по умолчанию τ₀=6).
4. **Морфология**: дилатация маски на 1 блок (запас на границу движения) + удаление одиночных изолированных блоков (выбросы шума).
5. **Опорный кадр (кадр 0) не маскируется никогда.** В зоне движения, где замаскированы почти все кадры, результат автоматически вырождается в «демозаиченный опорный кадр» — резкий, без призраков; отдельное заполнение дыр не нужно (покрытие из опорного кадра всегда ненулевое благодаря Catmull-Rom сплаттингу).

Ключевое отличие от неудачи с `ShiftGrid` (выключен из-за потери детализации): маска только **удаляет** семплы, не перемещает их — фазовая решётка вне движения не меняется.

## Изменения по файлам

**`src/types.rs`**
- `MotionParams { enabled: bool (false), sensitivity: f32 (1.0) }`; `MotionMask { cols, rows, step, blocked: Vec<u8> }` c быстрым `blocked_at(x, y)` в сенсорных координатах.
- `MergeParams`: + `motion: MotionParams`, + `masks: Vec<Option<MotionMask>>` (прецедент — `grids`; выровнено с `shifts`, учитывает `used_frames`-дедупликацию).
- `Shift`: + `masked_pct: f32` (0.0) — течёт в таблицу кадров GUI и `inspect`.
- `MergeStats`: + `masked_pct: Vec<f32>` (на входной кадр) + `masked_samples: u64`.

**`src/motion.rs` (новый)**
- `pub fn masks(frames, shifts, params) -> Vec<Option<MotionMask>>` — детекция по шагам выше; параллельно по кадрам (rayon). Оценка стоимости: одна решётка + один ресемплинг + разность на кадр (~6 М отсчётов решётки) ≈ 1–3 с на 32 кадра — вписывается в бюджет (сейчас 15.7 с из 120 с целевых).
- Чистая функция → тестируется отдельно.

**`src/shift.rs`** — `luma_plane`, `Plane` → `pub(crate)`; в `motion.rs` обратное преобразование координат (сдвиг+поворот → инверсия).

**`src/merge.rs`**
- `FrameView`: + `mask: Option<&MotionMask>`.
- В `run_band` (merge.rs:413–476), сразу после вычисления `(x, y)` и до сплаттинга: `if let Some(m) = f.mask { if m.blocked_at(x, y) { continue; } }` — одна ветка во внутреннем цикле.
- Статистика: маскированные семплы считаются в `MergeStats`.

**`src/app/pipeline.rs`** — `merge_frames`: при `params.motion.enabled && params.align` вычислить маски и подставить в params перед `merge::merge` (пути CLI и GUI сходятся здесь).

**UI/CLI (по образцу `deconvolve`)**
- `EditOptions`: + `motion_enabled: bool`, `motion_sensitivity: f32` → `merge_params()`. Действуют при следующем «Объединить» (как деконволюция).
- GUI, вкладка «Параметры»: чекбокс «компенсация движения» + слайдер чувствительности 0.25–4.0; таблица кадров — колонка «маска %»; строка лога после слияния с суммарной долей маски.
- CLI: `--motion` (включение), `--motion-sensitivity F`; сводка `merged ... masked X.X % (max Y.Y % frame N)`; `inspect --motion` печатает маску% на кадр (маски считаются на лету — кадры и сдвиги уже есть).

## Верификация (по собранным данным /Volumes/mac_drive/nikon/experiment/109NZ6_3)

Синтетика (`tests/merge_synthetic.rs`, по образцу `sixteen_frames_scale_two_reach_40_db`):
- сцена с движущимся объектом (сдвигается по кадрам): маскированное слияние строго лучше немаскированного по PSNR в зоне движения; статическая зона не хуже;
- сцена без движения: masked_pct ≈ 0, PSNR не отличается от базового слияния (контроль ложных срабатываний);
- чувствительность: порог τ=∞ эквивалентен выключению.

Реальные 9 серий (32 кадра, у каждой NEFX-эталон NX):
- **1–2 (штатив, статика)**: маска ≈ 0 % — контроль ложных срабатываний; метрики validate.py против NEFX не хуже текущних.
- **3, 7 (с рук, статика)**: маска мала; проверка, что IBIS-дрожь не даёт ложных масок.
- **4, 5 (большое движение), 6 (малое)**: визуальные кропы и доли маски; в замаскированных зонах — нет призраков (сравнение с NEFX, где они есть у NX).
- **8–9 (вентилятор 50 об/мин)**: фон остаётся резким, лопасти маскируются.
- Новый инструмент `tools/motion_panel.py`: кропы 1:1 в заданных координатах из четырёх источников (наш без маски / наш с маской / NEFX NX / одиночный кадр) в одну PNG-панель + карта маски; прогон по всем 9 сериям.
