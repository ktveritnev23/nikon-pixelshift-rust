# tools/ — проверочные инструменты

Требуют LibRaw CLI (`unprocessed_raw`, `dcraw_emu`, `raw-identify`), ImageMagick и python3
с numpy/scipy/PIL. Все скрипты ничего не меняют в исходных .NEF/.NEFX.

- `accept.sh [outdir]` — полная приёмка: релизная сборка, слияние всех четырёх серий,
  сверка с эталонами NX, печать таблицы. Результат: `out/*.dng` + отчёты в
  `.scratch/accept/`.
- `validate.py OUT.dng --ref SERIES/_DSCnnnn_merged.NEFX` — сравнение с эталоном NX:
  сдвиг, корреляция яркости, корреляция/усиление/PSNR по каналам, отношение детализации,
  PNG с кропом 1:1.
- `resolution.py OUT.dng --ref ... --single SERIES/_DSCnnnn.NEF` — прирост разрешения
  относительно одиночного кадра, увеличенного 2x; трёхпанельный PNG.
- `coverage_check.py` — покрытие выходной сетки для идеальных наборов смещений
  (показывает, что каждый пиксель получает R, G, G, B).
- `coverage_measured.py` — то же для реально измеренных положений серии 106.
- `pattern_probe2.py SERIES FIRST COUNT` — субпиксельный замер сдвигов по
  CFA-фазо-инвариантной проекции (самотест точности встроен).
- `nx_resolution.py` — сравнение эталона NX 4 кадра (после 2x-апскейла) с эталоном
  16 кадров: показывает, что NX действительно восстанавливает 2x-детализацию (5x по
  энергии лапласиана).
- `nefxgeom.py file.NEFX` — разбор TIFF/IFD структуры .NEFX (размеры, биты, сжатие).
